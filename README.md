# SadakSuraksha AI 🇮🇳 (सड़क सुरक्षा)

Multimodal AI, Cross-Modal Fusion, False Positive Filter, Pan-India 16 States, Google Maps 1-Click Redirects, Citizen Portal `/report`, Ingestion Feeds, AI Co-Pilot.

## Component Directory Breakdown
- `frontend/`: UI
- `backend/`: FastAPI server
- `database/`: Schema and seed scripts
- `docs/`: Architecture & APIs
- `tests/`: Pytest suite

## Quickstart
### Windows
`start.bat`
### Linux/macOS
`./start.sh`
### Docker
`docker-compose up -d`
